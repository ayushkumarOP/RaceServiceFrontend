# RaceService Frontend

This repository contains the frontend application for RaceService.

- Tech stack: TypeScript, React, Vite (or your chosen framework).
- Purpose: Provides the web UI for interacting with the RaceService backend: viewing races, managing participants, and monitoring live updates.

Getting started (development):

1. Install dependencies:

   npm install

2. Run the dev server:

   npm run dev

3. Build for production:

   npm run build

Notes for contributors:

- The frontend communicates with the RaceService backend API. Configure API base URL in the environment or `src/config.ts`.
- Keep UI components small and focused; add tests for new features.

Contact: maintainers in the repo for access or onboarding information.
